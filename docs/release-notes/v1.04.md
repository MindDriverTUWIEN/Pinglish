## Pinglish 1.04

Type Persian in Latin letters, or just speak it, and get proper Persian script.

**[English](https://github.com/MindDriverTUWIEN/Pinglish#readme) | [فارسی](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/README.fa.md)**

### Install

1. Download **`Pinglish-Setup-1.04.exe`** below.
2. Run it. No administrator rights and no Python needed.
3. Start **Pinglish** from the Start menu.

Windows SmartScreen may say *"Windows protected your PC"* because the installer
is not digitally signed yet. Click **More info → Run anyway**.

### What's new in 1.04

- **Only one Pinglish at a time:** opening Pinglish while it already runs
  brings its window to the front (also from the tray) instead of starting a
  second copy.
- **Installer knows what is installed:** it asks before installing the same
  version again, says when it updates an older version, and asks before
  replacing a newer version with an older one. Settings and word corrections
  are always kept.
- A tiny window size saved while Pinglish was hidden in the tray is no longer
  kept.

Full list: [CHANGELOG.md](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/CHANGELOG.md)

### Checksum

GitHub shows the SHA-256 checksum next to the installer under **Assets**.
Check your download in PowerShell: `Get-FileHash .\Pinglish-Setup-1.04.exe`
