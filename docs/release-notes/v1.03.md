## Pinglish 1.03

Type Persian in Latin letters, or just speak it, and get proper Persian script.

**[English](https://github.com/MindDriverTUWIEN/Pinglish#readme) | [فارسی](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/README.fa.md)**

### Install

1. Download **`Pinglish-Setup-1.03.exe`** below.
2. Run it. No administrator rights and no Python needed.
3. Start **Pinglish** from the Start menu.

Windows SmartScreen may say *"Windows protected your PC"* because the installer
is not digitally signed yet. Click **More info → Run anyway**.

### What's new in 1.03

- **Privacy:** the installer shows the [privacy policy](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/PRIVACY.md)
  and lets you turn speech recognition off. Then the mic records and sends
  nothing.
- **Built from source on GitHub:** this installer was built by the public
  GitHub Actions workflow from this repository's code.
- The mic works right after installation (Chromium's public speech key built in).
- Optional: use your own Google Cloud Speech-to-Text key.
- User files now live in `%LOCALAPPDATA%\Pinglish`.

Full list: [CHANGELOG.md](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/CHANGELOG.md)

### Checksum

GitHub shows the SHA-256 checksum next to the installer under **Assets**.
Check your download in PowerShell: `Get-FileHash .\Pinglish-Setup-1.03.exe`
