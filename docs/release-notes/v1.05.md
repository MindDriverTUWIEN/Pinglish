## Pinglish 1.05

Type Persian in Latin letters, or just speak it, and get proper Persian script.

**[English](https://github.com/MindDriverTUWIEN/Pinglish#readme) | [فارسی](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/README.fa.md)**

### Install

1. Download **`Pinglish-Setup-1.05.exe`** below.
2. Run it. No administrator rights and no Python needed.
3. Start **Pinglish** from the Start menu.

Windows SmartScreen may say *"Windows protected your PC"* because the installer
is not digitally signed yet. Click **More info → Run anyway**.

### What's new in 1.05

- **Microsoft Store package:** each release now also builds a Microsoft Store
  (MSIX) version of Pinglish. It is tested automatically before release:
  installed, started, checked to run only once, and removed again. The Store
  listing follows after Microsoft's review.
- In the Store version, Windows asks before Pinglish uses the microphone for
  the first time, and starting with Windows can be switched on in
  **Settings → Apps → Startup**.
- Nothing changes in how the .exe version works.

Full list: [CHANGELOG.md](https://github.com/MindDriverTUWIEN/Pinglish/blob/main/CHANGELOG.md)

### Checksum

GitHub shows the SHA-256 checksum next to the installer under **Assets**.
Check your download in PowerShell: `Get-FileHash .\Pinglish-Setup-1.05.exe`

### Code signing

The installer is not code-signed yet. It is built only from this repository's
public source code by GitHub Actions. Check the SHA-256 checksum above before
running it. See the [code signing policy](https://github.com/MindDriverTUWIEN/Pinglish#code-signing-policy).
